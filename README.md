# Flappy Bird Game

A simple implementation of the classic Flappy Bird game using HTML5 Canvas and JavaScript. Fully responsive and optimized for both desktop and mobile devices.

## How to Play

1. Open `index.html` in your web browser
2. Press **SPACE** or **Click/Tap** to start the game
3. Press **SPACE** or **Click/Tap** to make the bird flap and fly
4. Avoid the pipes and the ground
5. Try to get the highest score!

## Features

- Simple and intuitive controls
- Score tracking
- Smooth animations
- Responsive game physics
- Game over and restart functionality
- **Mobile responsive** - works on all screen sizes
- **Touch support** - play on mobile devices with tap controls

## Game Controls

### Desktop
- **Spacebar** or **Mouse Click**: Make the bird flap

### Mobile
- **Tap anywhere on the screen**: Make the bird flap

## Running the Game

Simply open the `index.html` file in any modern web browser. No server or build process required!

The game automatically adjusts to your screen size and works on:
- Desktop browsers
- Mobile phones (portrait and landscape)
- Tablets

## Technologies Used

- HTML5 Canvas
- JavaScript (ES6+)
- CSS3 with responsive design
- Touch event handling for mobile devices
